**SHIKARDOS AUDIO 1.1.68** · build 226 · Android 8.0 and newer

Fixes reported by listeners:

- **Apple Lossless (ALAC) in m4a plays.** On many phones these songs used to "play" in silence; now our own FFmpeg decodes them — from the library and when you open a file from a file manager with "Open with". The format line now says ALAC instead of AAC.
- **A song that won't open no longer stops the album.** The player shows a message and moves on to the next song; it pauses only when there is nothing left to play.
- **DTS files without a stored duration play** through our FFmpeg.
- **CUE sheets spanning several files** (for example vinyl sides A and B) are split into songs. If the file name inside the sheet doesn't match the disk, the player takes the audio file named like the sheet itself ("Side A.cue" finds "Side A.flac").
- **Sorting by title, artist and album follows the alphabet bar**: invisible characters, quotes or brackets at the start of a tag no longer move a song out of place. The sort menu marks the active order with a check, separately for Tracks and Folders.
- **DFF (DSD) plays through a USB DAC**: the player used to request 352.8 kHz, and on DACs without that rate the song stayed at 0:00. DFF now goes at 176.4 kHz, like DSF.
- **Loudness normalization keeps its measurements** for songs with long non-Latin file paths.
- **Crossfade no longer skips a song** and no longer moves the volume slider.
- **Radio:** a steady-stream station shows "Buffering" while it builds its reserve instead of a paused Play button; if a station fails to start, the previous song stays in place, paused. The 101.ru service reply is no longer shown as the song title.
- **Library:** FLAC, MP3 and other files in folders outside the Android media catalog (for example with .nomedia) now get tags, duration and cover art. Cloud songs show their length in the notification.
- **USB DAC:** the audio format of 24-bit UAC1 DACs is read correctly, and the DAC mode line shows the bus speed.
- **Translation:** the settings screen and remaining Russian labels are translated into all 18 languages. The Guide button opens the new website, in English for the English interface.
- **Hi-Res radio:** the FLAC catalog now has 164 stations.

Installs over the previous version; settings and library are kept.
